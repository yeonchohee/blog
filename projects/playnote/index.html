Playnote

인쇄된 악보 PDF를 올리면 음표를 인식해 화면에 띄우고 소리로 들려주는 웹 앱입니다. FastAPI, oemer, React, OpenSheetMusicDisplay, Tone.js

프로젝트 소개

만들게 된 계기

밴드 멤버가 자작곡을 PDF 악보로 줬는데 들어 볼 방법이 없었다. 찾아본 악보 재생 앱과 서비스는 다 유료라, 혼자 사용할 용도로 만들어 봄.

언어

서버: Python악보 인식 엔진(oemer)이 Python 라이브러리라 Python 으로 선택.
서버: FastAPI서버가 할 일이 세 가지 뿐이라, FastAPI의 기본 기능을 사용하여 몇 줄로 해결. (1. PDF 파일 받기 2. CORS 3. 에러 응답 돌려주기)
브라우저: React업로드 상태, 페이지마다 달라지는 악보 칸 수, 재생 상태가 바뀔 때마다 화면을 맞춰 다시 그려야 했다. 상태만 바꾸면 화면을 맞춰 주는 React로 선택.
