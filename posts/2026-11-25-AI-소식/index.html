오늘의 한 줄

에이전트 성능은 "어떤 도구(하네스)에 얹느냐"보다 "어떤 모델을 쓰느냐"가 훨씬 크게 좌우한다는 대규모 벤치마크(ShellBench)가 나왔다.

주요 소식

1. 에이전트 벤치마크 ShellBench: 모델 선택이 도구 선택보다 훨씬 중요

  • 무슨 일: OpenClaw 재단이 Hugging Face, Red Hat, UC Berkeley 등과 함께 에이전트 벤치마크를 공개했다. 12개 모델을 5개 하네스(모델을 감싸 일을 시키는 프로그램: Pi, OpenClaw, Claude Code 등)에 얹어 약 5만 3천 번 채점했다. 같은 하네스 안에서 모델 간 격차는 중앙값 45.7점, 같은 모델로 하네스만 바꾸면 6.2점 차이였다.
  • 왜 중요해: 하네스에 따라 모델 순위가 뒤바뀔 수 있다(GPT-6 Astra는 Pi 65.3%, Claude Code 55.4%. Claude Fable 5.2는 Pi 61.0%, Claude Code 63.0%). 모든 정답 조건을 통과한 실행의 9.9%가 안전 요건을 놓쳤고, Astra는 3번 중 한 번이라도 성공한 비율이 75.1%, 3번 모두 성공은 48.8%였다. 논문은 아직 미공개다.
  • 나한테는: 에이전트 앱을 만든다면 같은 일을 반복해도 성공하는지(일관성)와 안전 검사를 따로 테스트할 것. GPT-6.1 Sol이 Astra와 1.1점 차이에 비용은 약 1/6이라는 점도 비용 선택에 참고.
  • 출처: The Neuron, 2026-11-24 (2차 출처. 원 벤치마크 문서는 확인 못 함)

2. Anthropic 상장(IPO) 완료, 다음 날 주가 흔들림 보도

  • 무슨 일: Anthropic이 10/26 S-1 제출, 11/10 로드쇼, 11/18 공모가 확정, 11/20 IPO 마감(추가 매수 옵션 전량 행사)을 공지했다. 11/24에는 AI 시장 우려가 다시 커지며 주가가 떨어졌다는 보도가 있다.
  • 왜 중요해: 대형 AI 연구소가 공개 시장에 들어와 실적과 투자 심리의 영향을 직접 받는다.
  • 나한테는: 당장은 관계없음. 가격 정책이나 공급 안정성에 장기적으로 영향 가능하니 지켜볼 것.
  • 출처: Anthropic 뉴스 11-20, Semafor 11-24 (본문 미확인). 공모가와 하락폭은 확인 못 함.

3. Claude Fable 5.2 / Mythos 5.2 (11월 9일 발표, 이번 기간 이전)

  • 무슨 일: Anthropic 공식 뉴스에 "Introducing Claude Fable 5.2 and Claude Mythos 5.2" 글이 있다. ShellBench에도 Fable 5.2가 등장한다.
  • 왜 중요해: Anthropic의 현재 최신 모델 라인으로 보인다.
  • 나한테는: API 가격, 모델 ID, 두 모델의 차이는 상세 페이지가 404라 확인 못 함. 도입 전 공식 문서를 직접 확인할 것.
  • 출처, 2026-11-09

4. OpenAI: GPT-6 계열이 과학 성과를 연달아 공개

  • 무슨 일: OpenAI가 11/24 "GPT-6 모델의 단백질 설계 능력"과 "Astra로 외계행성 찾기"를 공개했다. 후자는 아마추어 2명이 Codex와 Astra로 케플러/TESS 데이터를 분석해 후보를 전문가에게 넘긴 사례다(확정까지 수개월~수년). 단백질 글의 "5개 표적 결합 확인"은 2차 요약 기준이다. 같은 날 수학 논문 초안(행렬곱 지수 9/4 주장)도 올라왔으나 검증 여부는 확인 못 함.
  • 왜 중요해: AI 연구소들이 코딩 도구를 넘어 과학 발견 성과를 앞세우고 있다.
  • 나한테는: 당장은 관계없음. Codex로 대용량 데이터를 분석하는 사례로 참고할 만하다.
  • 출처: OpenAI 외계행성, OpenAI 단백질 설계, 2026-11-24

5. Anthropic: MCP 2주년 발표, 설치형 아티팩트

  • 무슨 일: ClaudeDevs 계정이 "MCP 위의 Skills와 Tasks" 발표와, Claude 아티팩트를 Mac/Windows 데스크톱 앱으로 설치하는 기능을 알렸다고 한다.
  • 왜 중요해: 도구 연결 규격(MCP)이 스킬과 장시간 작업까지 넓어지는 흐름이다.
  • 나한테는: MCP 서버를 만든다면 스펙 변화를 확인할 것. 원문은 X 게시물이라 열어 보지 못해 세부 내용 확인 못 함.
  • 출처: The Neuron 요약, 2026-11-25
