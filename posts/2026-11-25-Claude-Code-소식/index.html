설치된 버전: 2.1.332 / 최신 버전: 2.1.332 (2026-11-25 공식 changelog 기준) 확인 범위: 기존 소식지와 state.json이 없어 최근 2주(2026-11-11 ~ 11-25)를 기준으로 삼았어요. 날짜가 확인된 버전은 2.1.327(11-17)부터 2.1.332(11-25)까지예요. 추가 소식 없음: 같은 날 공식 changelog를 다시 열어 봤고 2.1.332보다 새 버전은 없었어요. 아래 내용은 유지하되, 다시 읽어 확인한 부분은 바로잡았어요.

꼭 알아야 할 것

  • 지금 설정(SessionEnd/Notification/SessionStart hook, frontend-design 플러그인, 스킬 /commit-push-pr, 에이전트 11명)을 직접 깨뜨리는 변경은 확인되지 않았어요. 아래는 해당될 수 있어서 알려요.
  • /code-review가 좁아졌어요 (2.1.328, 11-19): 대부분의 모델에서 버그와 CLAUDE.md 위반만 알려줘요. 정리/단순화는 /simplify를 쓰세요. 대상 없이 쓰면 기본 브랜치와 비교해 브랜치 전체를 봐요(2.1.329). reviewer 에이전트와 역할이 겹치는지 보세요. 출처
  • 예약 작업 다시 걸기 (2.1.329, 11-19): 이전 버전에서 저장한 예약 작업은 새 로그인 세션에서 다시 예약해야 해요. playnote에 scheduled_tasks.lock이 있어 해당될 수 있어요. 출처
  • computer-use라는 이름의 스킬은 예약됨 (2.1.332, 11-25): Mac에서 computer use를 켠 경우 같은 이름의 내 스킬은 로드되지 않아요. 지금 쓰는 스킬 이름과는 충돌 없어요(리눅스 사용 중). 출처
  • rm 승인이 더 엄격해짐 (2.1.330, 11-20): 루트나 홈 등을 겨냥한 rm 명령이 더 많이 승인 대상이 돼요. 출처
  • /export가 덮어쓰기 전에 물어봐요 (2.1.327, 11-17). 이 항목은 이번 재확인 때 페이지가 잘려 다시 읽지 못했어요(처음 기록 그대로).
  • 11월 30일 예정: 관리형 extraKnownMarketplaces의 플러그인 마켓이 자동 업데이트가 기본이 돼요(끄려면 "autoUpdate": false). 관리형 설정을 쓸 때만 해당해서 나는 해당 안 될 가능성이 큼. 또 검색 결과에 Opus 4.8 fast mode가 11월 30일에 없어진다는 글이 있는데, 제3자 글이라 공식 확인은 못 했어요. 출처

써 볼 만한 새 기능 (최대 5개)

  • /status로 설정 점검 (2.1.327): 고장 난 에이전트, 스킬, 명령, 출력 스타일 파일과 무시된 설정을 보여줘요(집 점검표 같은 것). 에이전트 11명과 스킬을 직접 만들어 쓰니 오타나 형식 오류를 찾기 좋아요. 세션에서 /status 입력. 출처
  • /tasks에 예약 작업, /loop, fork 표시 (2.1.329): 백그라운드로 돌아가는 일을 한 곳에서 보고 x로 멈춰요. 예약 작업과 /loop 최대 기간도 7일에서 30일로 늘었어요(2.1.330). 써 보기: /tasks. 출처
  • claude doctor의 API 연결 점검 (2.1.331): 연결이 안 될 때 원인을 먼저 보는 용도예요. 써 보기: 터미널에서 claude doctor. (이 항목은 처음 기록 그대로, 재확인 못 함) 출처
  • claude mcp add-json <name> - (2.1.327): MCP 서버 설정 JSON을 표준입력으로 넘겨서 토큰이 명령 기록에 남지 않아요. 세션 안에서는 안 돼요. 써 보기: 나중에 MCP를 연결할 때 터미널에서. 출처
  • MCP 서버의 스킬 (베타, 2.1.332): MCP 서버가 server:skill 형태로 스킬을 제공해요(/ 메뉴에 표시). 써 보기: 해당 MCP를 연결했을 때만 의미 있어요. 출처

그 밖의 변경 (한 줄씩)

  • 2.1.332 (11-25): PreSkillShellCommand hook 추가(스킬/명령의 인라인 셸 실행을 막을 수 있음), --model default는 기본 모델을 못 쓰면 이전 모델로 대체, Foundry 기본 모델은 Sonnet 5.5(claude-sonnet-5-5), Bedrock의 Sonnet은 4.5 유지, 예약 안내 문구가 "cloud scheduled task"로 바뀜(/routines는 그대로), OTel 기본 service.name 변경(데스크톱), 받아쓰기 시간 제한 늘어남, claude auth login은 저장 실패 시 종료 코드 1.
  • 2.1.331 (11-23): Windows 레지스트리 정책(HKLM)이 managed-settings.json보다 우선, PermissionDenied hook의 retry: true는 사용자가 그 호출을 원했을 때만 재시도하라고 알림, 플러그인 manifest에 optionalDependencies, CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION, 여러 클라우드에서 Code Mode 지원.
  • 2.1.330 (11-20): 예약 작업과 /loop 최대 30일, 차트용 "easel" 내장 mod, deniedMcpServers 이름 항목은 지정한 claude.ai 커넥터만 숨김, max_tokens 자동 재시도 제거를 되돌림.
  • 2.1.329 (11-19): Code Mode에서 스크립트 출력에 UserPromptSubmit hook이 더는 실행되지 않음(가리려면 PostToolUse의 updatedToolOutput), /code-review 대상 없으면 브랜치 전체.
  • 2.1.328 (11-19): /bug는 보내기 전에 Yes/No 확인, /list-agents는 나에게만 보임, Bedrock 등에서 Opus 4.6/Sonnet 4.6 auto mode, 프롬프트 hook에 모델 별칭 사용 가능, mcp_tool hook의 onFailure: block(이 둘은 처음 기록 그대로).
  • 2.1.327 (11-17): /tui classic 이름 추가(/tui default도 계속 됨, 내 설정 "tui": "fullscreen"은 그대로), ExitWorktree가 저장 안 된 작업이 있을 수 있는 워크트리를 지우기 전에 물어봄, /install-github-app은 저장소를 바꾸기 전에 확인(처음 기록 그대로).
  • 2.1.326 이하: 2.1.326(Code Mode와 agent teams 지원, 시작 시 잘못된 권한 항목 경고), 2.1.325(zstd 보안 수정), 2.1.323(Code Mode 실험적 도입)이 확인됐지만 날짜는 확인 못 함.
  • Anthropic 발표 (2026-11-09): "Claude Fable 5.2"와 "Claude Mythos 5.2" 모델 발표. Claude Code에서의 사용 가능 여부와 기본 모델은 확인 못 함. 출처
  • 11-10, 11-18, 11-20의 IPO 관련 발표는 Claude Code와 무관해서 생략해요.

확인하지 못한 출처

  • changelog 전체: GitHub 원문은 약 142만 자라 앞부분(2.1.332 ~ 2.1.323)만 읽었어요. 그 이전 구간과 2.1.320 ~ 2.1.326의 날짜는 확인 못 함.
  • 공식 문서 "What's new" 주간 요약은 9월(37주차)까지만 있어서 11월 내용은 없었어요.
  • claude.com/blog: 열어 보지 않음(확인 못 함).
  • 제3자 글(havoptic, claude-world 등): 버전과 날짜가 서로 맞지 않아 사용하지 않았어요.
  • 이전 소식지: 없음(폴더와 state.json이 없었어요).
